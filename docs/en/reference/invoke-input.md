## KernelClient.invoke

`client.invoke(inputs, sessionId, providerSession, agentEnv)` returns a KernelInvocation async iterator. It validates, assigns identity and snapshots inputs at call time, submitting on first consumption.

| Argument | Type and Behavior |
| --- | --- |
| inputs | Required ModelInputPart[] or InvocationContent; see below and [Input Parts](input-parts.md) |
| sessionId | Optional non-empty string; undefined asks the client to generate it. Business identity, not Provider recovery. |
| providerSession | Optional complete opaque ProviderSession; undefined starts fresh. See below. |
| agentEnv | Required schema/items envelope. Empty items are valid but do not establish executability. [AgentEnv](agent-env-standard.md) |

### InvocationContent

The advanced form contains content, output mode and tracing fields, not agentEnv, sessionId, providerSession or signal.

| Field | Type | Requirements and Defaults |
| --- | --- | --- |
| `parts` | `ModelInputPart[]` | Required advanced content, 1–128 parts; low-level name is inputs. |
| `protocol_mode` | `"native" \| "canonical"` | Optional, default native; must match Adapter output support. |
| `invocationId / runId` | `string` | Optional non-empty strings generated by the client when absent; cancellation and Run correlation respectively. |
| `sessionName` | `string` | Optional, 1–256 Unicode code points and at most 512 UTF-16 units; no controls or whitespace-only names. Display only; Core supplies a UUID if absent. |
| `sessionGeneration / providerEpoch` | `number` | Optional non-negative safe integers owned by the caller for session generation and Provider binding epoch. AgentEnv changes do not increment them. |
| `prompt` | `string` | Optional non-empty display description, defaulting to an input text summary; does not replace Provider text. |
| `modelInput` | `string` | Optional non-empty complete primary text; replaces only text-only primary input. |
| `runMetadata` | `Record<string, unknown>` | Optional JSON object for tracing, not model text or authorization evidence. |
| `continuityMode` | `"fresh" \| "continue"` | Optional; defaults to continue with providerSession, fresh otherwise. Actual recovery failures follow Provider contracts. |
| `freshFallbackModelInput` | `string` | Optional non-empty complete recovery text, below recovery parts in priority. |
| `freshFallbackModelInputParts` | `ModelInputPart[]` | Optional complete recovery parts, same shape as primary input; retain current images in order. |
| `freshFallbackImagesUnavailable` | `boolean` | Optional; true explicitly fails if fresh fallback is entered. |

Text/image fields, budgets, integrity and primary/recovery selection are defined in [Model Input Reference](input-parts.md).

### ProviderSession

Save and return the complete object from the previous session.update, rather than only sessionId. Its required sessionId is a non-whitespace string. Optional resumable and requireResume are booleans; resumeOutcome is new/resumed/fresh_fallback/compacted; resumeFallback is a string; contextInputVariant is primary/recovery. Preserve Provider extension fields. Business sessionId does not replace this recovery handle.

A business session does not establish recovery compatibility across Adapters, accounts or servers. See identity and ownership in [Identifiers](../concepts/identifiers.md) and [Session Guide](../guides/context-and-sessions.md).

## Handles, Interruption and Cleanup

run.invocationId, run.runId and run.sessionId are immediately available. Unconsumed handles count toward the client's 128-record limit. Consume them or release through return(), throw(), interrupt() or owner drain. client.interrupt(run.invocationId, reason?) targets the original invocation owned by this client.

Interruption before submission prevents sending and iteration throws an error recognized by isInvocationNotSubmitted. After submission, keep consuming the original stream to its terminal. Ending observation of an accepted run does not cancel execution. Admission ACK, interruption ACK, execution terminal, business delivery and resource cleanup are separate facts; see [Output and Control](output-and-control.md).

## Low-level InvokeInput and IPC v2

CLI JSON/client.submit uses this shape. Rename InvocationContent.parts to inputs and flatten sessionId/providerSession/agentEnv. Other content fields are unchanged.

```json
{
  "inputs": [{ "type": "text", "text": "Inspect the prepared project." }],
  "sessionId": "conversation-42",
  "protocol_mode": "canonical",
  "agentEnv": {
    "schema": "octo.context-envelope/v3",
    "items": [
      { "namespace": "octo.execution", "name": "adapter", "payload": { "type": "codex" } },
      { "namespace": "octo.execution", "name": "workspace", "payload": { "path": "/absolute/prepared/project" } }
    ]
  }
}
```

InvokeInput.check validates the JSON boundary; the Adapter validates execution semantics. inputs and agentEnv are required; unknown top-level fields are rejected. Advanced submit/subscribe callers own complete RunRef, cancellation and tail observation outside the invoke registry. The transport limit is 32 MiB.
